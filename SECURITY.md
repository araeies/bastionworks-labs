# Security policy

Lab kits in this repository deploy deliberately vulnerable resources into the learner's own subscription. That is intended behaviour and not a vulnerability by itself.

Please report, privately:
- anything that makes a kit affect resources **outside** the learner's lab resource group or subscription;
- anything that lets a release, kit or `bw` be tampered with, or that weakens release signing or verification;
- secrets, answers or other private material accidentally published here;
- any way to make the Bastionworks Verifier contact systems other than the learner's own lab resources.

**How to report:** use GitHub's private vulnerability reporting ("Report a vulnerability" under the Security tab). Please don't open public issues for security problems.

We aim to acknowledge reports within 5 working days. There is no bug bounty.
