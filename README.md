# Bastionworks labs

Lab kits, the `bw` command-line tool and the `labspec` library for **Bastionworks**, a self-directed Azure cloud security program.

Learners deploy these kits into **their own** Azure subscriptions. Everything that runs in a learner's account is published here so it can be inspected before it runs.
