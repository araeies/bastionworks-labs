For the IaC checkpoint, define the storage account in **Bicep** in your own public repo (Terraform isn't supported by the checker yet), with **your** account name (the one `bw deploy` printed) as a literal or as a parameter's default value. Set `allowBlobPublicAccess: false` and `allowSharedKeyAccess: false`. Then save your incident note as `incident-note.md` at the root of the same repo and check it against `rubrics/incident-note.md`: it asks for the exposure window, what the token could access, how you revoked it, and how you know it worked.
